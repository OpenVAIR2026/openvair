## 运行概览

登录后的首页：

![运行概览](/docs-img/overview.webp)

- **运行状态**：需要关注的渠道，以及未开启可用性监控的渠道数。
- **请求统计**：请求量、成功率、失败数、平均首字延迟；「查看失败调用」跳到失败列表。
- **最近调用**：最新 5 次请求，可只看失败的。
- 刚安装时显示「开始使用」卡片：添加渠道、创建 Key、接入客户端。

## 使用分析

![使用分析：按时间、模型和渠道查看请求和费用](/docs-img/usage-analytics.webp)

按**渠道**、**API Key**、**时间范围**（近 24 小时、7 天、30 天、全部）筛选；图表可按请求数、Token 数、费用或输出性能统计。

| 指标 | 含义 |
| --- | --- |
| 总请求数 | 请求数及成功比例 |
| 总 Token | 输入加输出 |
| 缓存率 | 命中上游提示词缓存的输入 Token 占比 |
| 平均耗时 | 平均时长及首字时间 |
| 首字时间 | 发出请求到收到第一个输出 |
| 输出速度 | 每秒输出 Token，只统计成功的流式请求，排除输出少于 32 Token 的 |

- **渠道表现**：按渠道对比请求数、成功率、Token、缓存率、估算费用、延迟和输出速度。失败分为「请求错误」（参数或鉴权）、「服务异常」（上游或网关）和「其他未成功」。
- **费用**：只统计能计价的请求；未定价的模型单独标出，图表中对应时段为琥珀色。估算方式见[限额与费用](/docs/limits#费用是怎么算的)。

## 调用明细

页面底部列出每次请求，可按渠道、API Key、模型、协议和状态筛选，可导出 CSV。不保存对话内容；被网关直接拒绝的请求（如额度用完）不出现。点击一行查看详情：

![请求详情：耗时分解和每个渠道的尝试过程](/docs-img/request-detail.webp)

- **耗时分解**：「并发排队」→「前序渠道尝试」→ 最后一个渠道的「发出 → 响应头」「响应头 → 首个输出」→「首个输出 → 结束」。
- **渠道尝试**：依次尝试的渠道、耗时和失败原因（上游错误、连接或发送失败、连接或响应超时、首字超时（已切换渠道）、响应中断、客户端断开）。
- **用量与费用**、**请求记录 ID**（反馈问题时提供）。

请求慢时如何看耗时分解，见[问题排查](/docs/troubleshooting#请求很慢)。
