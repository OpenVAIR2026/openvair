拿到 API Key 后，在 [查看我的 Key](/my-key) 页粘贴，即可查看状态、额度、可用模型和调用记录，并复制接入配置。**无需帐号。**

## 打开页面

入口：直接访问 [{{origin}}/my-key]({{origin}}/my-key)、登录页下方的「只有 OpenVAIR Key？查看额度与接入方式」，或报错信息中的链接。

粘贴 Key 后点「查看」。「在此浏览器记住这把 Key」在公共电脑上不要勾选，用完点右上角「清除 Key」。

![粘贴 Key 后点「查看」](/docs-img/my-key-entry.webp)

## 概览

![「我的 Key」页：状态、额度、可用模型和接入方式](/docs-img/my-key.webp)

| 状态 | 含义 |
| --- | --- |
| 正常 | 可以调用 |
| 已暂停 | 被发放方停用，请联系发放方 |
| 今日已用完 | 页面显示恢复时间 |
| 额度已用完 | 总费用用完，需发放方提高上限或重置 |

- **额度**：今日 Token、今日费用、累计费用的用量和上限，以及每分钟请求数、并发上限和每日重置时间。
- **可用模型**：按协议分组，**点击模型名即可复制**。Claude Code 只能用 Anthropic 分组，Codex 只能用 OpenAI 分组。
- **接入方式**：推荐在 [OpenVAIR Desktop](/docs/desktop) 填服务器地址和 Key，一键写好本机配置；也可选择工具，点「复制配置」（已填好地址、完整 Key 和模型名）。

## 用量

「用量」标签显示所选时间内的请求数、Token、费用、平均耗时、趋势图和按模型分布，以及「调用明细」（点击一行查看耗时分解）。被直接拒绝的请求（如额度用完）不出现在明细中。

此页不能修改设置，也看不到渠道信息；需要调整时联系发放方。
