API Key 是工具调用 OpenVAIR 的凭据，每把单独设置权限和额度。自用可多台设备共用一把；按设备、人或用途分开创建，可分别查看用量、单独撤销。

## 创建 Key

1. 「API Key」→「创建 API Key」。
2. 按下表填写，点「创建 API Key」。
3. 在弹出面板中点「复制完整 API Key」。面板下方附有各工具的接入配置。

![创建 API Key 表单](/docs-img/key-create.webp)

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| Key 名称 | 用途，如「MacBook」「CI」 | — |
| 持有人（可选） | 发给了谁，便于搜索 | 空 |
| 分组 | 列表可按分组筛选 | 不分组 |
| 接入渠道 | 勾选「允许全部渠道」时新增渠道自动可用 | 全部渠道 |
| 允许模型 | 具体名称、前缀（如 `claude-*`）或「允许全部模型」 | 必填，无默认 |
| 每分钟请求数 | 留空不限 | 60 |
| 并发上限 | 最大 100 | 4 |
| 用量限制 | 每日 Token、每日费用、总费用 | 不限 |

限额含义见[限额与费用](/docs/limits)。

## 复制完整 Key

点列表中 Key 前缀（如 `openvair_AbC…`）旁的复制按钮，每次复制都记入[操作日志](/docs/account#操作日志)。显示「不可复制」的早期 Key 只存了哈希，无法找回，需重新创建。

## 查看接入方式

持有人推荐用 [OpenVAIR Desktop](/docs/desktop) 粘贴 Key 一键接入本机工具。手动配置时，在「更多操作」（⋯）→「接入说明」选择工具即可看到已填好地址和模型名的配置；「复制配置」会填入完整 Key。

![「接入说明」面板：按客户端给出配置，可直接测试连接](/docs-img/key-connect.webp)

面板中的「测试连接」只查询可用模型，不调用上游，不产生费用。

## 停用、重置和撤销

均在「更多操作」（⋯）菜单中。

| 操作 | 效果 | 可恢复 |
| --- | --- | --- |
| **停用** | 暂停，请求返回「已暂停」 | 能，随时重新启用 |
| **重置今日用量** | 今日 Token 和费用重新计算，累计不变 | — |
| **重置全部用量** | 每日和累计都重新计算 | — |
| **撤销** | 永久作废并从列表移除 | 不能 |

重置不删除调用记录。

![「更多操作」菜单](/docs-img/key-more-menu.webp)

> [!WARNING]
> 怀疑泄露时请**撤销**后新建。停用只是暂停，重新启用后旧 Key 仍可用。

## Key 的状态

| 状态 | 含义 |
| --- | --- |
| 启用 | 正常可用 |
| 停用 | 已手动停用 |
| 已达上限 | 拒绝新请求；每日上限次日北京时间 08:00 恢复，总费用上限不自动恢复。调高上限或重置用量可立即恢复 |

![API Key 列表：每把 Key 的用量、费用和限速](/docs-img/keys-list.webp)

## 自定义 Key 前缀

默认 `openvair_`，在「帐号设置 → 连接信息 → API Key 前缀」修改，规则见[帐号设置](/docs/account#api-key-前缀)。
