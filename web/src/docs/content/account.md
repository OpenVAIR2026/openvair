控制台只有一个帐号：首次安装时在 `/setup` 页创建的管理员。其他人使用 [API Key](/docs/keys)。

## 帐号信息

「帐号设置」中可修改：

- **帐号名称**：控制台中显示。
- **登录邮箱**：需当前密码和发到新邮箱的 6 位验证码（10 分钟内有效），需先在「系统管理 → 邮箱设置」配置发信邮箱。
- **登录密码**：10–256 个字符，不能与当前密码相同。

修改邮箱或密码后，其他设备自动退出，当前设备保持登录。同一邮箱 15 分钟内登录失败 10 次将被暂时限制，15 分钟后可重试。

### 忘记密码

已配置发信邮箱时，在登录页点「忘记密码？」用验证码重置。否则在服务器运行以下命令，按提示输入新密码（10–256 个字符）：

```bash
openvair admin reset-password admin@example.com
# Docker Compose 部署：
docker compose exec openvair openvair admin reset-password admin@example.com
```

重置后所有设备退出登录。

## 登录设备

「登录设备」列出已登录的浏览器和最近活动时间，可「退出」单台设备或「退出其他设备」。

## API Key 前缀

默认 `openvair`。1–32 个字母、数字、连字符或下划线，以字母或数字开头，只影响之后新建的 Key。

## 告警邮件

[渠道监控](/docs/monitoring)发现问题时发邮件到登录邮箱，需先配置发信邮箱。三类可分别开关，默认只开启渠道可用性。

| 提醒 | 发送时机 |
| --- | --- |
| 服务体检 | 服务体检确认异常 |
| 计量异常 | 确认用量虚报或隐藏系统提示词（精确比对一次不通过，或估算连续两次不通过）；无服务体检可确认时，真实流量中发现即发送 |
| 渠道可用性 | 持续不可用超过 30 分钟，或上游拒绝渠道密钥（401–403）；恢复时再发一封。同一渠道每天最多一次，短暂抖动不发 |

服务体检和计量异常在问题新出现时发一次，问题消失后重新计算；计量异常由服务体检和真实流量共用记录，同一问题只发一封。
