## 关于产品

### OpenVAIR 会提供模型额度吗？

不会。额度和费用来自你接入的渠道，OpenVAIR 只做转发、路由、限额和统计。

### OpenVAIR 和 CC Switch 有什么区别？

CC Switch 切换单台电脑上的工具配置；OpenVAIR 是服务器网关，所有设备共用一个地址，并能分发 Key、设置额度、监控渠道。两者可一起用，见 [CC Switch](/docs/other-clients#cc-switch)。

### 支持哪些模型？

使用 OpenAI 兼容、Anthropic Messages 或 Gemini 协议的对话模型，包括本机或内网服务。不支持向量、图片、音频等接口，见[支持的接口](/docs/api#支持的接口)。

### 能把 OpenAI 格式的请求转给 Claude 吗？

不能，OpenVAIR 不做协议转换，见[协议必须一致](/docs/concepts#协议必须一致)。可接入以 OpenAI 兼容协议提供 Claude 的渠道（很多中转站提供）。

## 关于使用

### 修改了渠道或 Key 的设置，客户端要重启吗？

不用，服务端即时生效。

### 可以给团队成员开控制台帐号吗？

不可以。给每位成员发一把 Key，在「持有人」注明归属；成员在[查看我的 Key](/docs/my-key) 查看额度，无需登录。

### 我能看到成员用 Key 发了什么吗？

不能。OpenVAIR 不保存对话正文，只记录元数据，见[数据与隐私](/docs/privacy)。

### 忘记了管理员密码怎么办？

见[忘记密码](/docs/account#忘记密码)。

## 关于费用

### 费用限额准确吗？

费用是估算值，且额度在请求开始前检查，可能略超上限，见[费用是怎么算的](/docs/limits#费用是怎么算的)。

### 监控和测试连接会花钱吗？

| 操作 | 费用 |
| --- | --- |
| 添加渠道时的「测试连接」、可用性检查 | 每次输出 1 个 Token，极少 |
| 服务体检 | 少量，设置处显示预估 |
| 长上下文检测 | 较高，发起前显示预估 |
| 被动检查、Key「接入说明」中的「测试连接」 | 免费 |

## 关于安全

### 供应商 Key 放在 OpenVAIR 安全吗？

供应商 Key 加密保存在你的服务器上，不下发到客户端；设备上只有可单独撤销的 API Key。详见[数据与隐私](/docs/privacy)。
