# OpenVAIR 和同类项目的对比

OpenVAIR 只覆盖团队共用模型渠道的场景，换取更少的配置和使用步骤。其他项目变化较快，下表只概括定位，以各项目最新文档为准。

## 同类项目

| 类型 | 代表项目 | 主要用途 |
|---|---|---|
| API 分发面板 | one-api、new-api | 聚合渠道，按额度分发，支持充值 |
| 通用 LLM 网关 | LiteLLM Proxy、Portkey、Higress / Kong 的 AI 插件 | 为应用提供统一 API、路由和观测 |
| 本地配置切换工具 | cc-switch、claude-code-router 等 | 在本机切换 Agent 的上游配置 |
| 托管路由服务 | OpenRouter 等 | 无需部署，按量付费 |

## OpenVAIR 的取舍

| | OpenVAIR | 说明 |
|---|---|---|
| 自部署 | ✓ | 单租户，一个管理员 |
| 桌面客户端一键配置 Agent | ✓ | 断开时恢复原配置 |
| 每把 Key 的额度、速率、并发和模型 | ✓ | 按日或累计限制 Token 和费用 |
| 持有人自查用量 | ✓ | `/my-key` 页面，无需帐号 |
| 渠道故障自动切换 | ✓ | 按优先级，出错渠道短暂冷却 |
| 渠道可用性和质量监控 | ✓ | 可降低优先级或暂时剔除 |
| 请求级诊断 | ✓ | 记录切换过程和耗时，不存正文 |
| 多实例 / 高可用 | ✗ | 仅单实例 |
| SSO、多成员和角色 | ✗ | |
| 充值、计费和转售 | ✗ | 不在定位内 |
| 按 Agent 统计用量 | ✗ | 统计到 Key 一级 |

## 怎么选

- **团队共用上游，想让成员的 Agent 直接可用**：OpenVAIR。
- **只有自己，只想在本机切换上游**：本地配置切换工具。
- **为应用接入大量供应商，或需要多实例**：通用 LLM 网关。
- **对外分发或转售额度**：API 分发面板。
- **不想自己部署**：托管路由服务。
